## 🔧 Troubleshooting Common Issues

### The download won't start
Make sure you're clicking the actual download button, not a banner or ad. Sometimes browsers block automatic downloads - look for a notification at the top of your browser and click "Allow" if needed.

### The program won't open
Try right-clicking the Aniflow icon and selecting "Run as Administrator". This gives the program permission to work properly.

### The video has no sound
Check that your computer's volume is turned up, and make sure the voice narration isn't muted in the Aniflow settings.

### It's taking too long
This is normal for longer comics. If it's been over 30 minutes, try closing other programs and restarting Aniflow.
